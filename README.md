# Analisis Nilai Impor Indonesia 2025 (v2)

Jalankan: `npm install` lalu `npm run dev` (build: `npm run build`).

Shortcut: panah kiri/kanan, Space, PageUp/PageDown = navigasi; Home/End = slide pertama/terakhir; F = layar penuh; Esc = keluar.
Pada slide dengan insight, tombol kanan memunculkan insight dulu sebelum pindah slide.
Data (src/data.js) tidak diubah. Angka turunan dihitung dari data tersebut.
